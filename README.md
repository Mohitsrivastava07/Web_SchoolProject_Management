# Web_SchoolProject_Management
A comprehensive Web Application School Project Management System built with Spring Boot, Spring Security with login or register page, Thymeleaf, PostgreSQL, HTML, CSS, JavaScript, and Bootstrap for managing students, teachers, admissions, contact, enquiries, or also customize (in which CRUD operations performs) and administrative operations.

------------------------------------Features-----------------------------------------
📊 Interactive Admin Dashboard
👨‍🎓 Student Management (Add, Update, Delete, View)
👩‍🏫 Teacher Management
📝 Admission Management
📞 Contact Management
❓ Enquiry Management
🏫 Campus & Academic Modules
📈 Real-time Dashboard Statistics
🔍 Search Records
✔️ Form Validation
📱 Fully Responsive User Interface
🔐 Secure Spring Boot MVC Architecture
💾 PostgreSQL Database Integration
🎨 Modern Glassmorphism UI Design
